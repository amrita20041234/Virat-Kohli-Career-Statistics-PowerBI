# 🏏 Virat Kohli Career Statistics – Power BI Dashboard

## 📊 About the Project

This is a Power BI dashboard created to explore and analyze Virat Kohli's cricket career statistics.

I built this dashboard to practice data cleaning, analysis, DAX, and dashboard design using Power BI. It focuses on making the statistics easy to understand through interactive visuals rather than just showing raw numbers.

## 📌 What the Dashboard Shows

The dashboard includes:

* Total Runs
* Total Innings
* Batting Average
* Strike Rate
* 4s and 6s
* Runs by Year
* 50s and 100s
* Year Range selection
* Format selection for ODI, Test and T20I

## 🛠️ Tools Used

* Power BI
* Power Query
* DAX
* Data Visualization

## 🔍 About the Analysis

The yearly performance chart makes it easier to see how the number of runs changed over the selected period.

The dashboard also provides filters for year range and format, allowing the data to be explored based on different selections.
